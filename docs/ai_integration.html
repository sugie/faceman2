240b45d（push 済み）

設計方針

スコア計算は残したまま、その上に AI を重ねる

既存の判定ロジックを AI に置き換えるのではなく、判定結果を AI に渡して「なぜこの人がこのジャンルに向いているのか」を書かせる。こうすると、通信が失敗しても診断結果そのものは必ず表示される。デモ中に会場の回線が落ちても発表は止まらない。

Mac での手順

  1. pull してテンプレートを複製する

    1 分 
    git pull
cp ios/Secrets.sample.swift ios/Secrets.swift

  2. APIキーを貼る

    1 分

    ios/Secrets.swift を開き、sakuraAPIKey に発行済みのキーを入れる。

  3. Xcode に 2 ファイル追加する

    2 分
    ファイル扱い
    ios/AIComment.swift 追加する APIクライアント + 結果画面のカード
    ios/Secrets.swift 追加する キーを貼ったもの
    ios/Secrets.sample.swift 追加しない Secrets が二重定義になる
    ios/BikeFitApp.swift 差し替え 更新済み。古いコピーを使っているなら入れ直す

  4. ⌘R

    1 分

    結果画面の最上部に「AI による診断」カードが出る。

動きかた

11 問の回答と、スコア計算で出した第一候補を Kimi に渡し、「なぜこの人がこのジャンルに向いているのか」を回答の具体的な中身に触れながら書かせる。毎回文面が変わるので、デモで回すたびに違う結果が出る。

  • 送っている内容

    「身長のレンジ → 160-170cm」のように、質問文と選んだ選択肢のラベルを 11 行ぶん。加えてスコア計算による第一候補のジャンル名。

  • 出力の制約

    日本語・150〜200 文字・箇条書きや見出しは使わない・地の文のみ。結果画面のレイアウトが崩れないようにしてある。

デモを壊さないための作り

ここが今回いちばん気を使った部分。

状況画面の挙動
通信中 「あなたの回答を読んでいます…」とスピナー
成功 AI が書いた診断文を表示
失敗・タイムアウト 「ネットワークにつながらないため省略しました」と静かに表示。その下のスコア診断・ジャンル説明・上位 3 件はそのまま出る
キーが未設定 同上。ビルドは通るし、アプリは完動する

エラーは観客に見せない。

失敗の原因は #AI05 として Xcode のコンソールにだけ出す。画面には技術的なエラーメッセージを一切表示しない。

公開リポジトリなので 1 点だけ厳守

APIキーを AIComment.swift に直接書かないこと。

このリポジトリは PUBLIC。AIComment.swift はコミット対象なので、キーを書くと公開され、数分でスクレイピングされる。キーは必ず ios/Secrets.swift にだけ置く。

ios/Secrets.swift は .gitignore に登録済みで、効いていることを確認してある。

$ git check-ignore -v ios/Secrets.swift
.gitignore:60:ios/Secrets.swift    ios/Secrets.swift

詰まりそうな点

症状原因と対処
Palette が見つからない BikeFitApp.swift の更新が反映されていない。private enum Palette から private を外した版が必要
Secrets の二重定義 Secrets.sample.swift をターゲットに追加してしまっている。外す
HTTP 401 キーの貼り間違い。#AI03 としてコンソールに出る
モデル名エラー AIComment.swift の static let model を変更する

利用可能なモデル一覧はこれで取れる。

curl https://api.ai.sakura.ad.jp/v1/models \
  -H "Authorization: Bearer $KEY"

発表での言い方

実装と一致していて、突っ込まれても説明できる言い方はこれ。

11 の質問への回答を AI が読んで、その人に向けた診断文を生成しています。

スコア計算が候補を出し、AI がその理由を語る構成なので、「AI が何をしているのか」を正直に説明できる。AI が単独で判定しているわけではない点だけ、聞かれたら答えられるようにしておくとよい。

時間が足りなくなったら、AI カードは入れずにビルドを通すことを優先する。

既存部分だけで完全に動く。AIComment.swift を追加しなければ、BikeFitApp.swift のカード呼び出しだけがビルドエラーになるので、その 3 行を消せば元に戻せる。
