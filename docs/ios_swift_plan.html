リポジトリ：新規作成は不要

sugie/faceman2 が既に存在し、同期済みで、しかも PUBLIC だった。新しく作る理由が今日はない。

  • PUBLIC なので Mac 側の認証が要らない — これが一番効く

    Windows の SSH 鍵は Mac にはない。origin は SSH URL だが、public リポジトリなら HTTPS で clone すれば認証ゼロで通る。鍵の設定でハマる時間をまるごと回避できる。

  • 新規リポジトリ作成は今日やらない

    5〜10 分かかって、今日得るものがない。整理はイベント後で足りる。

Windows → Mac の引き渡し

  1. Windows から push する

    2 分 
    git add ios/ tools/ docs/ memo/ CLAUDE.md
git commit -m "Find My Motorcycle: Laravel診断をSwiftネイティブへ移植"
git push

  2. Mac で clone する — HTTPS + 履歴なし

    3 分

    --depth 1 で過去の 66MB を引かずに済む。composer install は不要。iOS 側は Laravel に一切依存しない。

    git clone --depth 1 https://github.com/sugie/faceman2.git
cd faceman2

保険：git が詰まったら ios/ だけ渡せばいい。

Mac 側が必要とするのは ios/ フォルダ（25MB）のみ。Laravel 本体も Docker も composer も使わない。USB メモリでも iCloud でも、何らかの手段で ios/ が Mac に届けばビルドできる。git でハマったら即座にこちらへ切り替える。

移植の根拠：SQL は全部ただの配列引きだった

Laravel の処理 Swift での置き換え
DB::select("SELECT id FROM bf_questions ORDER BY id") 配列の添字
BfWeight::where(question_id)->where(option_id)->get() choice.scores（15 要素の配列）
BfAnswer::where(bf_diagnosis_id)->get() @State var picked: [Choice]
bf_users / bf_diagnoses への保存 削除 結果に影響しない
bf_diagnosis_scores / bf_recommendations 削除 どこからも読まれていない

データ総量は質問 11 / 選択肢 47 / ジャンル 15 / 重み 705（47 × 15 の密なマトリクス、値は 0・30・40・50 の 4 種のみ）。合計 16KB。採点は Laravel 版と同一挙動（同点時は ID の小さい方）。

先につぶしておいた地雷

  • アプリアイコンのアルファチャンネル

    App Store Connect はアルファ付きアイコンを弾く。24bit RGB で描き直して透過なしにした（生成後に検証済み）。TestFlight のアップロードで止まらない。

  • @main の重複

    Xcode はプロジェクト名から FindMyMotorcycleApp を自動生成する。こちらのエントリポイントは MotorcycleApp に改名して衝突を避けてある。

  • 画像の追加作業

    元画像が既に 1024×1024 だったのでリサイズ不要。Contents.json 込みで imageset を 15 個生成済み。当初 20 分と見ていた工程が フォルダ 1 個のドラッグになった。

  • iPhone 12 mini の画面幅 375pt

    トップのタイトルを 2 行組み + minimumScaleFactor で収まるようにした。

  • 画像がなくても落ちない

    結果画面は UIImage(named:) で存在を確認してから描画する。アセットを飛ばしてもアプリは完全に動く。

残っているリスク

Swift コードはコンパイル未検証。

Windows に Swift ツールチェーンがないため構文チェックができていない。Mac での初回ビルドで細かいエラーが出る可能性がある。SwiftUI の基本 API しか使っていないので大崩れはしないはずだが、手順 05 に余裕を取ってある。ここが唯一の不確定要素。

デモ時の注意：診断結果がネイキッドに寄る。

加点合計はネイキッド 1020 点に対し、最少のレーサーレプリカは 90 点。全 15 ジャンルとも理論上は出るが、何度か回すと同じ結果が続く。問診票の設計そのものの話なので今回は触っていない。デモで散らしたいなら、別ジャンルが出る回答パターンを 1 本用意しておくのが最短。

イベント後の宿題（今は無視してよい）。

このリポジトリは PUBLIC だが、docker-compose.yml に MySQL の root パスワードが、docker_settings/httpd/_env_* に APP_KEY などが平文でコミットされている。今日始まった問題ではなく既に公開済みの状態なので、今は止まらず進めてよい。イベント後にローテーションを検討する価値がある。
